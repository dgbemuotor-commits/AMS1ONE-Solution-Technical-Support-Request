# AMS1ONE Solutions — Technical Support Request

A responsive technical-support request website concept built for AMS1ONE Solutions Ltd.

## Included
- Violet and lilac visual theme with a technology image hero background
- Responsive navigation and a quick scroll-to-top button
- Support request form covering customer contact details, issue category, urgency, location and description
- Approval workflow overview: submission → coordinator review/approval → repairer assignment → service completion/feedback
- Repairer and maintenance directory transcribed from the supplied Technical Support Request PDF
- Basic on-page SEO metadata for AMS1ONE Solutions and the project author, Deborah Florence Gbemuotor
- Accessible form labels, mobile layouts and contact links

## Important functionality note
This is currently a front-end prototype. Submitting the form prepares a request summary and a mailto link for the company; it does not create a database ticket, notify a coordinator automatically, authenticate approvers, or persist approval status. A production workflow needs a backend or form/ticket service with secure storage, notifications, role-based approval and status tracking.

## Publish with GitHub Pages
1. Open this repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose branch **main** and folder **/(root)**, then save.
5. Wait for GitHub Pages to publish and open the URL shown in Settings → Pages.

## SEO note
Metadata helps search engines understand the page, but it cannot guarantee that a site appears when someone searches a name. After publishing, add the final public URL to a sitemap, verify the site in Google Search Console, and link to it from the author's portfolio/LinkedIn profile. Search indexing takes time.
